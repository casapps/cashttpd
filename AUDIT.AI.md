## Completed
- uis: **CRITICAL** — mode dispatch ran before argument parsing and recognized
  only `--daemon`, so from any interactive terminal `serve`, `--version`,
  `--help`, `--config-test`, and `--licenses` all fell into the TUI stub and
  the binary was functionally inert. CI never caught it because CI has no TTY.
  `src/uis/mod.rs` now forces CLI for all print-and-exit flags, `serve`,
  `--quiet`, and `NO_COLOR`. Verified under a real PTY.
- docker: `docker/Dockerfile` CMD and all three compose `command:` arrays
  omitted the `serve` subcommand, so the container parsed its own arguments as
  top-level flags and exited non-zero without ever serving.
- servers: `parse_cli_overrides` matched only the space form, so `--port=9090`
  validated at the CLI and was then silently dropped onto a random port.
- cli: `--debug` was `serve`-only despite being a universal flag (AI.md:1208).
- cli: added `--licenses` / `--credits` printing the embedded `LICENSE.md`
  (AI.md:2169-2175); `src/assets.rs` now actually embeds it, and
  `.dockerignore` re-includes `LICENSE.md` so the `include_str!` still
  resolves inside the Docker build context.
- cli: `--version` hardcoded the binary name instead of deriving it from
  argv[0] (AI.md:1220).
- ci: `actions/attest-build-provenance` was pinned to a SHA that does not
  exist (GitHub API 422) — every release provenance step would have failed.
  Corrected to the real v3.0.0 SHA across GitHub/Gitea/Forgejo.
- ci: `actions/download-artifact` was pinned to a v5.0.0 SHA mislabeled
  `# v6.0.0` and running node20, which runners drop 2026-09-16. Bumped to
  v8.0.1 (node24).
- ci: job-level `permissions:` blocks in `ci.yml` (publish-devel-image) and
  `release.yml` (publish-image) replaced the workflow-level block and dropped
  `contents: read`, breaking `actions/checkout`.
- ci: `.gitlab-ci.yml` and `Jenkinsfile` still built the deleted
  `docker/Dockerfile.build` (AI.md:832 forbids it for Rust), breaking both
  providers' license-compliance and SBOM jobs; `docker/README.md` still
  documented it. All now run directly against `casjaysdev/rust:latest`.
- deny: added the AI.md:2096-2104 `[licenses] deny` array.
- format: `size()` exited the unit loop before rounding, so 1048575 rendered
  as `1024 kilobytes` instead of `1 megabyte`.
